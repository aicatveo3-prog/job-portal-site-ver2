## 주요 기능

1. **8개 사이트 통합 수집**
   * 고양시 일자리망 · 한국장애인고용공단 · 고용24 · 서울시장애인일자리센터 · 잡알리오 · 사람인 · 모두의잡 · 잡아바
   * **PDF · HWP · HWPX · DOCX 첨부 공고문 자동 텍스트 추출** 및 상세창 첨부파일 다운로드 바로가기
   * **자동 제외 직무** (`config.py`의 `EXCLUDED_ROLE_KEYWORDS`): 미화·청소 · 요양보호사 · 네일아티스트 · 조리사 · 버스운전직 · 바리스타 · 설거지
   * 최근 3개월(95일) 마감 공고까지 누적 보관
2. **OpenCode Go (`opencode-go/deepseek-v4.1-flash`) 자동 정제**
   * 비장애인 일반직원 노이즈 자동 제외
   * 기관 구분 · 장애 정도(중증/경증) · 계약 기간 · 근무 시간(전일제/단시간) · 급여 · 접수 마감일 · 타지역 거주 제한 자동 추출 + 쉬운 3줄 요약
   * `state/ai_cache.json` 캐시로 매일 신규 공고만 AI 처리
3. **장애인 친화 웹사이트 & 한국어 근무지역 지도**
   * 글자 크기 3단계 · 고대비 모드 · 시급/월급 예측 연봉 자동 환산 · 실시간 접수마감 판별
   * 기본 필터: `공공·지자체` · `접수중` · `전일제(주5일↑)` · `경증도 지원 가능` · `신규 공고 우선` *(지자체 장애인일자리사업은 맞춤 조건 `🏛️ 장애인일자리`로 별도 분리)*
   * **근무지역 지도 보기** (OSM 한국어 지도, 고양시 반경 10km/20km 원, 동별·구별 핀, 직선 거리 표시)
4. **완전 방치형 자동화 & 알림**
   * PC 로그인 2분 후 + 매일 오전 9시 백그라운드 숨김 실행 (하루 1회 제한, 인터넷 최대 60초 자동 대기)
   * GitHub Pages 자동 푸시 + Windows 토스트 알림 + 매일 1통 카카오톡 「나와의 채팅」 브리핑
